# Tools

Used to build the server's config pak (`ServerInstall.ps1`) and to read the game's fonts (WSDS, setup).

| File | Source | License |
|------|--------|---------|
| `repak.exe` | https://github.com/trumank/repak/releases | MIT / Apache-2.0 (`LICENSE-MIT`, `LICENSE-APACHE`) |
| `retoc.exe` | https://github.com/trumank/retoc/releases | see `LICENSE-retoc` |
| `oo2core_9_win64.dll` | Epic Games' Oodle library, shipped with Unreal Engine games | proprietary - not included; copy it from a UE5 game install |

Place the files in this folder before running `BuildInstallers.ps1`.
